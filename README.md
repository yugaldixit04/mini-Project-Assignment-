# 🌟 Interactive Profile Mini-Project

Ek chhota aur simple web project jisme HTML, CSS, aur JavaScript ka use karke ek interactive profile banayi gayi hai. Yeh project beginner developers ke liye DOM manipulation aur event listeners sikhne ke liye ek perfect practice hai.

---

## Features (Hum isme kya kar rahe hain?)

1. Theme Toggler:
   - Ek button (`Toggle Theme`) diya gaya hai jiske click karne par website light mode se dark mode (aur vice versa) mein switch hoti hai.

2. Like Counter:
   - Users profile ko like kar sakte hain. Har click par like count dynamically increase hota hai aur screen par real-time update hota hai.

3. FAQ Accordion / Toggle:
   - Ek "What do I do?" button hai. Is par click karne par ek hidden answer show/hide hota hai, sath hi accessibility ke liye `aria-expanded` attribute bhi properly manage hota hai.

## Technologies Used

- **HTML5:** Page ka structure aur semantic elements ke liye.
- **CSS3:** Styling, smooth transitions, aur Dark Mode support ke liye.
- **JavaScript (ES6+):** DOM manipulation, event listeners, aur interactivity ke liye.
